# 🛒 Superstore Sales Performance Analysis

## 📊 Project Overview
An end-to-end Excel data analysis project analyzing 9,994 sales 
orders from a US retail superstore across 4 years (2014–2017).
Built as a portfolio project to demonstrate core data analyst skills.

## 🎯 Business Questions Answered
- Which region generates the most revenue and profit?
- Which product categories are most and least profitable?
- How do sales trend across months and years?
- Which customer segments deliver the best returns?

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Interactive Slicers
- Conditional Formatting
- Excel Formulas: SUMIF, IF, IFERROR, DAYS, DATEVALUE

## 📁 Project Structure
| File | Description |
|------|-------------|
| `Superstore_Raw.csv` | Original raw dataset |
| `Superstore_Clean.xlsx` | Cleaned data + analysis + dashboard |

## 📋 What I Did — Step by Step
1. **Data Cleaning** — removed duplicates, fixed date formats,
   standardized currency and percentage columns
2. **Feature Engineering** — created 4 calculated columns:
   Profit Margin %, Delivery Days, Revenue Category, Profit Status
3. **Analysis** — built 4 pivot tables answering key business questions
4. **Dashboard** — interactive dashboard with slicers filtering all
   charts simultaneously
5. **Insights** — written business recommendations based on findings
